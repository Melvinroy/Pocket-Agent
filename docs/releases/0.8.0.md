# Release 0.8.0

## Summary

`0.8.0` adds host-side worktree binding and terminal preset execution to Pocket Agent so a thread can run lint, test, or build inside the active worktree without exposing direct shell control to the client.

## Highlights

- workspace worktree discovery and active binding
- controller-gated terminal preset execution on the host
- worktree and preset status in the mobile shell
- integration coverage for worktree-bound preset runs

## Upgrade Notes

- no schema migration is required for this milestone
- arbitrary shell streaming and richer worktree lifecycle management remain follow-up work
