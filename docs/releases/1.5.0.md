# Release 1.5.0

## Summary

Pocket Agent `1.5.0` adds a live command console to the thread shell. Recent host preset runs now stay visible inline, and new `turn.output` events append over websocket transport so controllers can inspect host `lint`, `test`, and `build` output without leaving the thread or relying only on timeline summaries.

## Highlights

- Added command log extraction from replayable thread timelines in the web data layer.
- Added a websocket-aware command console component for seeded and live host output.
- Kept the command console aligned with the existing thread transport and host-side event model.
