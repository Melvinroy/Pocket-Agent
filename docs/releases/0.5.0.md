# Release 0.5.0

## Summary

`0.5.0` introduces the first production-shaped mobile shell for Pocket Agent. The PWA now exposes workspace and thread views that reflect reconnect posture, controller presence, and a host-routed composer surface without exposing raw Codex App Server access.

## Highlights

- mobile dashboard for workspace posture and active thread entry
- workspace detail route with lease and thread context
- thread detail route with timeline preview, reconnect state, and composer shell
- expanded shared UI primitives and browser test coverage

## Upgrade Notes

- no external migration is required for this milestone
- follow-on milestones will replace seeded route data with authenticated live transport
