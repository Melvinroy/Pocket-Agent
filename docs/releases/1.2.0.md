# Release 1.2.0

## Summary

`1.2.0` adds the first in-app web pairing flow for Pocket Agent. The web shell can now start and confirm pairing against a host gateway, persist the resulting host session in secure cookies, and immediately use live discovery plus websocket transport.

## Highlights

- Next.js proxy routes for pairing and host session management
- cookie-backed host session for server-rendered live transport
- home-screen connect and disconnect panel in the web shell
- seeded fallback preserved when no live host session exists

## Upgrade Notes

- no new host migration is required for this slice
- the fastest local path remains `corepack pnpm --filter @pocket-agent/hostd dev -- --serve`
- richer in-app token rotation and multi-device session management remain follow-up work
