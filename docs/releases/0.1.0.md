# Release 0.1.0

## Summary

Initial scaffold release for Pocket Agent. Establishes the monorepo, architecture records, versioning policy, CI, and package skeletons for the host daemon, remote protocol, Codex bridge, persistence, security, workspace management, and web shell.

## Included

- `pnpm` + `turbo` monorepo
- Next.js mobile-first shell
- Host daemon bootstrap command
- Typed protocol and bridge skeletons
- Documentation, ADR, changelog, and progress scaffolding

## Known gaps

- No live Codex App Server process integration yet
- No persistence migrations yet
- No pairing and gateway flows yet
