# Release 0.4.0

## Summary

Pairing and gateway release. Pocket Agent now exposes a localhost host gateway with pairing start and confirm flows, short-lived access tokens, token revocation, role-aware session introspection, and controller-lease enforcement.

## Included

- pairing session service
- confirmation-code device onboarding
- short-lived bearer tokens
- revoke endpoint
- authenticated host session endpoint

## Known gaps

- websocket transport is not implemented yet
- token persistence is still in-memory
- mobile client flows are not wired to the gateway yet
