# Release 1.16.0

## Summary

Pocket Agent `1.16.0` turns the web Connect Panel into a real session-management surface. Connected devices now see their current host role, understand who holds the controller lease, and can switch between viewer and controller access without manually disconnecting and re-pairing.

## Highlights

- Added connected-session role and controller-lease visibility in the web Connect Panel.
- Added connected-session role switching through the Next.js host proxy.
- Fixed host token revocation so controller leases and device records stay in sync.
