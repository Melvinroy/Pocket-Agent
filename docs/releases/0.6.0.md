# Release 0.6.0

## Summary

`0.6.0` adds the first end-to-end timeline and approval control slice for Pocket Agent. The host now exposes authenticated timeline retrieval plus controller-only steer, interrupt, and approval resolution actions, while the mobile shell surfaces those controls and approval states.

## Highlights

- thread timeline endpoint backed by replayable host events
- controller-only steer and interrupt actions
- approval resolution flow with audit logging
- thread shell updates for approval sheets and control actions

## Upgrade Notes

- no migration changes are required for this milestone
- websocket transport and live push delivery remain follow-up work for the next slices
