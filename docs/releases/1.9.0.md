# Release 1.9.0

## Summary

Pocket Agent `1.9.0` adds a dedicated review history route so cross-workspace review work is not compressed into a single dashboard section. Controllers can now open a full-screen review surface and jump directly into the thread that needs attention.

## Highlights

- Added a `/reviews` route in the web shell for review queue and history inspection.
- Added review posture stats for pending, active, and recent items.
- Kept the route backed by the same live host review projection used by the dashboard queue.
