# Release 1.6.0

## Summary

Pocket Agent `1.6.0` adds a host-routed file editor to the web shell. Changed files can now be opened from workspace and thread views into a dedicated editor page, and controller devices can save edits back to the host through the existing gateway without exposing the desktop filesystem directly.

## Highlights

- Added a local web proxy route for host file reads and saves.
- Added a workspace file page and editor component with controller-gated saving.
- Linked changed files from workspace and thread screens into the editor flow.
