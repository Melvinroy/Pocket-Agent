# Release 1.13.0

## Summary

Pocket Agent `1.13.0` hardens the live web transport with host heartbeats, browser-side stale detection, reconnect and resubscribe logic, and explicit operator feedback across the home, review, thread, and command-console surfaces.

## Highlights

- Added websocket heartbeat messages from the host gateway.
- Added stale transport detection plus reconnect backoff and subscription replay in the shared browser transport.
- Added manual reconnect controls and transport status panels across the main live views.
- Blocked controller actions and terminal presets while the live transport is degraded.
