# Release 1.10.0

## Summary

Pocket Agent `1.10.0` adds filtering to the review history route so review work can be narrowed by state or workspace without losing the host-projected dashboard model.

## Highlights

- Added state filters for pending, active, and recent review items.
- Added workspace filters for cross-workspace review routing.
- Added empty-state handling when a filter has no matching review items.

- `corepack pnpm typecheck`
