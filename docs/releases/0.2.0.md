# Release 0.2.0

## Summary

Bridge alpha release. Pocket Agent now includes a host-only stdio bridge that can spawn a local process, exchange typed protocol envelopes, and stream bridge lifecycle and turn events back into the host daemon.

## Included

- stdio process bridge
- typed response envelope helper
- capabilities handshake validation
- fixture-based bridge contract tests

## Known gaps

- no real Codex App Server adapter mapping yet
- no persistence-backed replay yet
- no remote gateway or auth transport yet
