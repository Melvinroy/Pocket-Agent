# Release 1.4.0

## Summary

Pocket Agent `1.4.0` extends the live thread shell so the active controller can run host-side terminal presets from the phone or web. The thread screen now exposes host-routed `lint`, `test`, and `build` actions through a web-local proxy endpoint backed by the existing controller lease and bound worktree state.

## Highlights

- Added `/api/host/threads/[threadId]/commands/preset` to forward preset execution through the Next.js app.
- Added a terminal preset runner in the thread screen with controller gating, host status feedback, and route refresh on success.
- Added browser coverage for preset execution and controller-disabled behavior.
