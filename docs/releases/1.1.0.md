# Release 1.1.0

## Summary

`1.1.0` adds the first live host transport slice for Pocket Agent. The host gateway now exposes websocket timeline streaming plus discovery endpoints for workspaces and threads, and the web shell consumes that transport when host credentials are configured.

## Highlights

- websocket timeline subscriptions at `/api/ws`
- authenticated workspace and thread discovery routes on the host
- live web shell data loading with fallback to seeded demo content
- host `--serve` mode for local dogfooding with a seeded controller token

## Upgrade Notes

- set `POCKET_AGENT_HOST_URL` and `POCKET_AGENT_ACCESS_TOKEN` to use live transport in `apps/web`
- run `corepack pnpm --filter @pocket-agent/hostd dev -- --serve` for local bring-up
- in-app pairing UX for the web shell remains future work; this slice focuses on the transport and host contract
