# Release 0.3.0

## Summary

Persistence and replay release. Pocket Agent now has a SQLite-backed session store with typed schema definitions, startup migrations, thread replay primitives, approval persistence, paired device storage, controller lease tracking, and audit log support.

## Included

- SQLite session store
- Drizzle schema definitions
- startup migration runner
- replay and latest-event helpers
- controller lease conflict protection

## Known gaps

- host daemon does not yet boot with a durable store by default
- pairing and gateway transport are not implemented yet
- real Codex event replay still needs host integration
