# Release 1.14.0

## Summary

Pocket Agent `1.14.0` packages the first end-to-end dogfood fixes from running the web shell against a live local host: the dashboard hero layout now renders correctly, and controller-lease pairing conflicts produce actionable guidance in the Connect Panel.

## Highlights

- Fixed the shared phone-shell hero width bug uncovered on the live dashboard.
- Improved controller-lease conflict copy in the web pairing flow.
- Added regression tests for both dogfood issues.
