# Release 1.3.0

## Summary

Pocket Agent `1.3.0` makes the web thread screen actionable for the active controller. A paired controller can now steer the next turn, interrupt host execution, and resolve approval prompts through web-local proxy routes that forward to the host gateway with the cookie-backed host session.

## Highlights

- Added `/api/host/threads/[threadId]/steer` and `/api/host/threads/[threadId]/interrupt` to forward controller actions through the web app.
- Added `/api/host/approvals/[approvalId]/resolve` for approval decisions from the thread screen.
- Added a client-side thread action panel with status, error handling, and route refresh after successful actions.
- Fixed bridge stdio processing so mixed event and response chunks no longer strand pending requests.
