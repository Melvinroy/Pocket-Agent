# Release 0.7.0

## Summary

`0.7.0` adds host-scoped file browsing and light editing to Pocket Agent, along with a review-start trigger that remains inside the host gateway boundary.

## Highlights

- safe workspace file browsing with traversal protection
- authenticated file read and write routes on the host
- changed-file surfaces in workspace and thread views
- review-start action recorded as host timeline and audit activity

## Upgrade Notes

- no schema migrations are required for this milestone
- deeper diff editing and richer Codex review orchestration remain follow-up work
