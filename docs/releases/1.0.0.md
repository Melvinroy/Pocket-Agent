# Release 1.0.0

## Summary

`1.0.0` is the first stable public release candidate for Pocket Agent. The repository now ships a host daemon, mobile-first web shell, host-wrapped Codex bridge, local persistence, pairing and auth, approvals, file and review workflows, worktree-aware terminal presets, and OSS operator documentation under a consistent public package scope.

## Highlights

- Pocket Agent package scope and repository metadata aligned for public OSS use
- host-only Codex bridge and stable remote protocol boundaries
- durable session store with replay, approvals, devices, and controller leases
- mobile-first PWA shell with pairing, timeline, file, review, and worktree surfaces
- install, operator, threat-model, compatibility, and release-check guidance

## Upgrade Notes

- package imports now use `@pocket-agent/*` instead of `@codex-remote/*`
- rerun `corepack pnpm install` after upgrading to refresh lockfile metadata
- websocket streaming transport and richer deployment packaging remain follow-up work after this release candidate
