# Release 1.7.0

## Summary

Pocket Agent `1.7.0` lets the active controller start a host review directly from the web file editor. When a file is opened from a thread diff, the editor now preserves thread context and can trigger a host review without forcing the user back into the thread screen first.

## Highlights

- Added a local web proxy route for thread review start.
- Added a review launcher to the workspace file page when the file was opened from a thread context.
- Preserved controller gating so only the active controller can start host review actions.
