# Release 1.11.0

## Summary

Pocket Agent `1.11.0` adds live review-stream updates so the `/reviews` screen stays synchronized with host review activity over websocket instead of relying on request-time snapshots.

## Highlights

- Added typed `subscribe-reviews` and `reviews.snapshot` websocket messages.
- Added host-side review snapshot broadcasting from the gateway.
- Added a live review panel that updates counts and review items in place.

- `corepack pnpm test`
