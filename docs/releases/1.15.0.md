# Release 1.15.0

## Summary

Pocket Agent `1.15.0` removes a pairing dead-end in the web shell by letting operators fall back to viewer mode when another device already owns the controller lease.

## Highlights

- Added controller and viewer pairing mode selection before a session is established.
- Added a one-click viewer fallback action from the controller pairing state.
- Updated browser coverage for the new pairing copy and fallback flow.
