# Release 1.12.0

## Summary

Pocket Agent `1.12.0` reduces live-view websocket churn by introducing a shared browser transport that reuses one host connection across thread timeline, command-console, and review-queue subscriptions.

## Highlights

- Added a shared web transport client keyed by host websocket URL and access token.
- Deduplicated thread and review subscription messages across concurrent live views.
- Added browser coverage for socket reuse between the live timeline and command console.
