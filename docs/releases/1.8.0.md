# Release 1.8.0

## Summary

Pocket Agent `1.8.0` adds a review queue to the dashboard so the active controller can see review-ready threads and approval gates across workspaces without drilling into each thread shell first.

## Highlights

- Added a home-screen review queue with deep links into the relevant thread.
- Added live host mapping that turns thread review status and pending approvals into dashboard review queue items.
- Kept the seeded shell data aligned with the live route behavior for offline and demo flows.
